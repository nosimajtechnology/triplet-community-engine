# Start Here

## 1. Install

1. Download [triplet-community-engine.zip](https://github.com/nosimajtechnology/triplet-community-engine/releases/latest/download/triplet-community-engine.zip). Do not unzip it.
2. At [chatgpt.com](https://chatgpt.com), open **Plugins** -> **Skills** -> **Create** -> **Upload from your computer**.
3. Upload the ZIP and start a new chat.

## 2. Load it

```text
Load the "TripleT Community Engine" skill.
```

## 3. Describe one idea

```text
Make an image of TripleT waiting alone at a PS2-era bus stop before sunrise.
```

That is enough. You can name a mode, game reference, duration, or video model, but you do not have to.

The Engine is best at:

- recognizable TripleT images
- simple absurd premises played completely straight
- short PS2 game-world scenes
- deadpan bumpers and loading screens
- fictional commercials
- image-to-video prompts built from approved frames

For video, approve the first image before the Engine continues. It will prepare the motion prompt; you paste that into your video tool.
